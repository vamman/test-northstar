# Authored weather attendance response

The additive `northstar.weather-response.v1` district policy changes actual new departures. Work and school sample trips, road vehicle cohorts, social trips and event attendance are suppressed before records are created. Route origin and destination select the worst affected known district. New local demand is never increased by a legacy regional demand multiplier. Existing moving people, vehicles, gateway passengers already arriving, and named workers' return itineraries remain in place.

Registered Office workers use `worker:<worker_id>:<Atlantic shift date>` with the same hash cohort as Office; physical security, housekeeping, reception and facilities use the essential staffing fraction. Suppressed outward trips create a `weather_suppressed` commute history record, do not generate a return, and resume their normal recurring calendar on subsequent shifts. Named worker clocks remain independent between simulators. Worker-role decisions use origin and workplace districts.

The weighted road and sampled school/work population are separate authored demand layers, not named residents. Aggregate work has a 15% essential-service share; school and work homebound sample departures use the same reductions, while all actual in-flight identities and registered returns are protected. Empty scheduled public-transit vehicles may hold at a terminal under the service fraction, with recovery when conditions ease; occupied vehicles finish normally. Weather travel time is supplied once by the existing travel-time factor.

Worker-owned `weather_response_outcomes` reports actual requested/generated/suppressed records in the latest advance, cumulative suppression, named decisions (bounded to 100), essential and homebound permits, and terminal holds. `/api/environment`, the read-only MCP `get_environment_impact` tool and dashboard expose these results. Missing/malformed or expired observations apply neutral policy on the next worker step; manual local disruptions remain separate. These are deterministic scenario assumptions, not calibrated transport forecasts.
