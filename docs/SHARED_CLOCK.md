# Shared Northstar clock

When `NORTHSTAR_CLOCK_FILE=/northstar-clock/clock.json` is configured, this service
follows the durable Northstar coordinator. `GET /api/clock` returns the epoch,
authority target, committed local time, worker heartbeat and cutover provenance.
All eleven services (including every office building) must commit a minute before
the next minute is released. A failed or restarted worker resumes that same target;
an unavailable, expired or incompatible authority stops local advancement.

The initial requested pace is one simulated minute per four real seconds. Slow
processing lowers the effective pace for the entire region. Global pause finishes
an already released minute. Local pause, speed, jump/reset and manual advancement
are rejected with HTTP 409 in shared mode; other authenticated controls retain
their existing permissions. The dashboard status strip displays Atlantic time.
The native per-service speed fields are retained for standalone compatibility;
`/api/clock` is authoritative for shared mode and global pause status.

Bank state follows every shared minute, with its existing daily ledger settlement
at UTC midnight. No retroactive wages or production are generated by cutover.
Environment integrates at the common one-minute cadence in shared mode.

The initial cutover uses the latest saved simulator time, rounded up to a minute.
Historical event/measurement/ledger tables and immutable integration envelopes
retain their original timestamps. Active operational schedules are translated by
the service's cutover offset to preserve elapsed and remaining work; exact before
and after values are saved in `northstar_clock_audit`. Each office building has its
own recorded offset. Pre-cutover source times remain distinct; do not subtract
historical timestamps across services or across the cutover without provenance.
Calendar-driven activity uses the new shared date from cutover onward; the skipped
calendar interval is not modeled work. Existing office daily counters remain until
the next modeled daily boundary; pre-cutover elapsed-time backlogs are retained as
legacy metadata and not replayed. Identities and existing cumulative totals persist.

Clock coordinator and operator commands live in the regional Simulators workspace:
`clock/coordinator.py`; dashboard: http://127.0.0.1:8875. Clock configuration is
mounted read-only into applications. Its administrator token is outside that mount
and never supplied to MCP. Existing network bindings remain unchanged.

Without `NORTHSTAR_CLOCK_FILE`, isolated deployments/tests retain their original
independent-clock behavior. Do not disable it on an enrolled live simulator: that
would intentionally leave coordination. Back up all databases with writers stopped
before any cutover or recovery. See the regional `CLOCK.md` for deployment/recovery.
